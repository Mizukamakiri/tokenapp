A few things behind the numbers

Input covers instructions, history, files, tool results, and your prompts. Output covers generated text, tool calls, and reasoning. Cached input and reasoning are subsets; they are never added twice.

These are locally recorded Codex and Claude Code counts. The top selector switches between them. Regular ChatGPT and Claude web chats and other devices are outside this dashboard. Estimated costs apply current standard API prices to recorded usage; they do not reproduce a subscription bill or historical prices.

Imported history stays saved even if the original logs disappear. Daily database snapshots are kept in data/backups. Keep a copy on another drive for protection against disk failure.
